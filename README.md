## 一、快速开始

1. **打开原神**，切到要弹琴的角色：
   * 选「沃雅妮莎」并使用琴 → 进入沃雅妮莎的演奏 / 清唱界面；
   * 选其他角色 → 普通「风物之诗琴」状态。
2. **双击 `启动-原神弹琴.bat`**（或 `以管理员身份启动.bat`，见下文"按键没反应"）。
3. 在程序里：
   * 右侧选好乐器（默认就是「沃雅妮莎」）；
   * 左边点「导入谱子…」选 txt，或者直接把谱子粘贴进编辑框；
   * 设好「按键间隔 tick」（默认 150，1 tick = 1 毫秒）、「倒计时」秒数；
   * 点 **▶ 开始演奏**（或按快捷键 **F9**）。
4. 程序会先倒计时（**倒计时期间一个键都不按**），并自动把原神切到前台，然后开始弹。

> 建议做法：程序窗口默认"始终置顶"，即使在原神全屏（无边框窗口）时也能看到，
> 你可以按住 **Alt 点击**「开始演奏」按钮，这样原神不会被切走；随后程序自己把原神切回前台再开始弹。

## 二、琴谱写法

| 写法 | 含义 |
| --- | --- |
| `D D A B C` | 空格（或换行）分隔的音符，用「按键间隔」逐个按下 |
| **`BN`** | **紧贴**：按完 B 后紧贴（快速）按 N，间隔 =「紧贴间隔」（可调） |
| **`N(DT)`** | **紧贴和弦**：按完 N 后紧贴按下和弦 D+T（两键同时按下） |
| `(HT)Q` | 和弦 (HT) 后紧贴按 Q；写成 `(HT) Q`（有空格）则 Q 用普通间隔 |
| **`A / B`** | **斜杠 = 停顿**：长度用界面上的「斜杠」参数（默认 300 tick） |
| `/[500]` `/@500` `/ (500)` | 单独指定这一次停顿的长度（覆盖「斜杠」参数） |
| `A/B` | 写在一起时，`/` 也是停顿（B 视作紧贴） |
| `(AH)` `(A,H)` `{AH}` | **和弦**：括号内的键同时按下（`[A H]` 也仍然可用） |
| `A[25]` `A [25 tick]` `A@25` | **单个音的时间标记**：默认含义"先等 25 tick 再按 A"（兼容旧写法 `A(25)`） |
| `A[0.5s]` `A[250ms]` | 时间标记支持单位 `tick`(默认) / `ms` / `s`（1 tick = 1 毫秒） |
| `(AH)[50]` `-[500]` | 和弦、休止都可以带时间标记 |
| `[300]` | 单独出现 = 纯等待 300（不按键） |
| `A*3` `Ax2` `BN*2` | 重复 3 次 / 2 次 / 紧贴串重复 2 次 |
| `-` `_` `.` `~` | 休止：停一拍，不按键（也占时间） |
| `# 注释` `// 注释` | 行内注释，到行尾的内容会被忽略 |

### 紧贴（快速连按）

* 写在一起、**中间没有空格**就是紧贴：`BN`、`N(DT)`、`(AH)(SF)`、`BNA`。
* 紧贴用的间隔由界面上的 **「紧贴间隔」** 单独控制（默认 40 tick），
  与普通的「按键间隔」互不影响。
* 空格 = 普通间隔。所以 `N(DT)` 是紧贴，`N (DT)` 就不是（想让带空格的括号和弦也算紧贴：
  设置 → 「紧贴」怎么判定 → 选第二项）。
* 一个音自带的时间标记 `[N]` 优先级：紧贴 > 时间标记 > 斜杠 > 全局间隔。

### 斜杠 `/`（停顿）

| 你的写法 | 效果 |
| --- | --- |
| `N(DT) / (HT)Q` | 两段之间停顿，长度 =「斜杠」参数（默认 300 tick = 0.3 秒） |
| `A /[1000] B` | 这一次停顿用 1000 tick，其他 `/` 仍按参数走 |
| `A // B` | ⚠️ 两个斜杠是**注释**（`//` 后面的内容会被忽略），不是停顿 |

停顿本身占「斜杠」tick，后面的音再加它自己的间隔，所以 `A / B`（间隔 200、斜杠 500）
两音之间实际是 500 + 200 = 700 tick = 0.7 秒。

### tick 与秒的换算

**1 tick = 1 毫秒，1000 tick = 1 秒。**

程序左下角（设置按钮右边）会实时显示当前参数的换算，例如：

```
1 秒 = 1000 tick ｜ 间隔 150 = 0.15 秒（约 6.7 音/秒）｜ 紧贴 40 = 0.04 秒 ｜ 斜杠 300 = 0.3 秒
```

改任何一个参数，这行数字立刻跟着变。

### 单个音的时间标记（tick）

例如 `A[25] B[30] C[35]`：

* **默认含义（设置里可改）**：数字属于它自己 —— 先等 25 tick 再按 A，再等 30 tick 按 B，再等 35 tick 按 C。
* 另一种含义：数字属于前一个音 —— 按 A 后等 25 tick 再按 B …
* **没有写标记的音符，用界面上的「按键间隔」**（默认值），所以两种写法可以混用：
  `A[200] B C[100]`，间隔设 300 → A 前等 200、B 前等 300、C 前等 100。
* 时间标记的含义在 **设置 → 谱子里的 (N) 时间标记** 里一键切换。
* 数值就是 tick（1 tick = 1 毫秒），上限 1 小时；写 0 或负数会被忽略。
* 时间标记请写在 `[ ]` 里（`( )` 已经被和弦/紧贴占用）；旧的 `A(25)` 写法仍然兼容。

其它细节：

* 全角括号、全角字母数字（例如 `（ＡＨ）`）会自动转换成半角。
* 大小写不区分：`a` 与 `A` 等价。
* 谱子里出现**不属于当前乐器键位**的符号时：会被当成休止处理，并在日志和"检查谱子"里明确提示（不会乱按键）。
* 括号含义可以切换：**设置 → 括号 ( ) 的含义 →  `chord`**（同时按，默认）/ **`repeat`**（依次按两次）。

示例文件在 `sheets\` 文件夹里：`示例-小星星.txt`、`示例-写法演示.txt`、`示例-单独间隔.txt`、`示例-紧贴与时间标记.txt`。

## 三、界面说明

| 位置 | 功能 |
| --- | --- |
| 上方「曲谱」标签栏 | 像 NotePad++ 一样同时打开多个曲谱（最多 12 个）。`＋ 新建谱子` 新建；点标签切换；**右键标签**可重命名 / 复制 / 关闭；`×` 关闭当前标签 |
| 「节奏区间」栏 | 把一个谱子拆成最多 **20 个区间**，按顺序演奏。`＋ 添加新区间演奏` 新建一个区间子页，`当前区间` 下拉切换，可重命名/删除 |
| 「本区间使用独立间隔」 | 勾选后该区间用自己的间隔（tick）；不勾选就用右侧的「按键间隔」。区间信息栏会实时显示 `共 N 区间 ｜ 共多少步 ｜ 约多少秒` |
| 「演奏行范围」 | 只演奏这个区间里的第几行到第几行，例如填 `11` 到 `22`；**留空＝从头弹到尾**。越界/倒序会自动纠正 |
| 左侧大字区 | 当前区间的谱子内容，可直接编辑 / 粘贴 |
| **右侧行号栏** | 像专业编辑器一样实时显示行号（可在设置里改成显示在左边），当前行高亮 |
| 行号下面的蓝字 | 实时显示 `第 N 行，第 M 列 ｜ 共 K 行`（填了行范围时会一起显示） |
| 「检查整首谱子」 | 逐个区间报告步数、间隔、耗时，并汇总整首的步数与预计演奏时间 |
| 「清空本区间」 | 只清空当前区间的内容 |
| 右侧「乐器」 | 沃雅妮莎（默认）/ 风物之诗琴，下面有键位预览（演奏时高亮当前键） |
| 右侧「谱子」 | 导入谱子…（任意 txt）/ 读取保存的谱子 / 保存谱子…（内容 + 各区间间隔 + 紧贴 + 斜杠一起存） |
| 右侧「演奏参数」 | 按键间隔 tick、紧贴、斜杠、按住时长、倒计时、自动切前台、失去焦点停止 |
| 右下「测试当前乐器的按键」 | 依次弹一遍当前乐器的每个键，用来对照游戏界面校准键位 |
| 左下角 **⚙ 设置** | 关闭行为、置顶、快捷键绑定等 |

> **自动记住**：所有标签页（含每个区间的内容与间隔）会在切换/退出时自动保存到 `session.json`，
> 下次打开程序原样恢复；就算没点保存也不会丢。

### 节奏区间怎么用（例：把一首曲子分成 3 部分）

1. 在「曲谱」栏点 `＋ 新建谱子`（或在现有标签里）。
2. 第一个区间默认叫「第1区间」，把第一部分谱子粘进去；
   想让它有自己的速度，就勾上「本区间使用独立间隔」并填 tick（例如 150）。
3. 点 `＋ 添加新区间演奏` → 出现「第2区间」子页，粘第二部分，设它自己的间隔（例如 250）。
4. 再点一次添加「第3区间」，设成 200。
5. 区间信息栏会显示 `共 3 区间 ｜ 57 步 ｜ 约 12.4 秒`；点「检查整首谱子」能看到每段的明细。
6. 点「开始演奏」→ 会**按第1、第2、第3区间的顺序**连续演奏（每段用各自的间隔）。

保存成 txt 时，多区间会写成这样（再载入能完整还原）：

```
# 原神自动弹琴 谱子
# 乐器: 风物之诗琴
# 间隔: 150
# 紧贴间隔: 40
# 斜杠间隔: 300
# 区间数: 2
# [区间1] 前奏 | 跟随全局
A B C
# [区间2] 高潮 | 独立间隔=250
G G H H G
```

### 设置里的项目

* **关闭窗口时最小化到任务栏（不退出程序）** —— 默认勾选。想真正退出：设置里点「退出程序」，
  或取消勾选后再点右上角 ×。
* **窗口始终置顶** —— 默认勾选（全屏时也能看到窗口）；
* **演奏时取消置顶** —— 默认**不勾**：**演奏期间也保持置顶**，这样原神全屏时你依然看得到本窗口、
  也能直接点「停止」（程序被游戏抢走置顶时，按一次开始/停止快捷键还会立刻把自己唤回最前面）。
  只有你主动勾上它，演奏开始后才会让位给游戏画面，演奏结束自动恢复。
* **下拉框不会再被"抢置顶"干扰**：打开设置窗口/菜单期间，程序会**临时让出置顶**，
  并保证对话框自己置顶，所以所有下拉选项都能正常点选（早期版本每 1.5 秒强行提升主窗口，
  会把下拉列表盖住导致闪烁、选不中，已修复：现在只在"置顶状态真的丢了"时才动窗口）。
* **原神失去焦点时立即停止演奏** —— 默认勾选，**强烈建议保持勾选**。
* **开始 / 停止快捷键（默认 F9）**、**紧急停止快捷键（默认 F10）** —— 点「绑定…」后按下新组合即可。
  规则：`F1~F12` 可单独使用，其他键必须搭配 `Ctrl / Alt / Shift`（避免把游戏正常操作吞掉）。
* **按键发送方式** —— 默认 `vk`（虚拟键码 + 扫描码，兼容性最好，已实测三种方式都能被系统正确投递）；
  游戏里没反应时，依次换 `scancode`、`keybd_event` 再试；
* **谱子里的 (N) 时间标记** —— 决定 `A[25]` 是"先等 25 再按 A"（默认）还是"按完 A 再等 25"；
* **「紧贴」怎么判定** —— 默认"只有紧挨着写（无空格）才算紧贴"；也可改成"括号和弦紧跟音符时
  （可带空格）也算紧贴"。紧贴用的间隔在主界面的「紧贴间隔」里调。
* **编辑器** —— 「显示行号」开关、「行号位置」选右侧（默认）或左侧；
* **免责声明与作者** —— 「启动时显示免责声明」开关、「重新查看免责声明」（只读）、
  「复制 QQ 号」、「关于」；声明本身固定唯一版本，不可编辑；
* **原神进程名 / 窗口标题** —— 默认 `YuanShen.exe, GenshinImpact.exe` 与 `原神, Genshin Impact`。
  用云原神或其它客户端时，把它的进程名加进来即可。
* **最大演奏时长** —— 兜底保护，超过就自动停。

### 演奏前预检（重要）

点「开始演奏」后，程序会先做一次**预检**，把下面这些可疑之处列出来问「是否继续演奏」：

* 某个区间是空的（会被跳过）；
* 某个区间的间隔 **小于按住时长**（会导致自动缩短按键时间、可能漏音）；
* 谱子里有**无法识别的符号**（中文、emoji、奇怪标点等，会按休止处理）；
* 填了**行范围**（提醒你只弹第 N～M 行）；
* 「紧贴」比「按键间隔」还大、斜杠停顿特别长、整首步数/行数特别多等。

整首一个音都没有时**直接拒绝演奏**。所有预检结果同时写进日志，方便排查。

## 四、安全机制（重点）

1. **只有原神在前台才会开始**：倒计时结束时会再检查一次，若原神不在前台，直接取消，不会乱按键。
2. **演奏中一旦离开原神立即停止**：有独立监控线程每 50 毫秒检查前台窗口，
   检测到切后台/切窗口会**立刻停止并松开所有按键**（连续两次确认，避免误判）。
3. **倒计时期间不按任何键**，方便你切回游戏。
4. **停止 / 异常 / 退出**都会统一释放按键，不会出现"卡键"。
5. **单实例**：重复启动会提示"程序已在运行"，避免两份程序同时抢键盘。
6. 演奏中的每一步都会再确认一次前台窗口，双保险。
7. 所有异常都写进日志（`logs\genshin_lyre.log`、`logs\faulthandler.log`），崩溃也能回溯。

## 五、乐器键位（几行？）

《原神》演奏系统是 **3 行 × 7 键 = 21 键**，键盘对应关系为：

| 行 | 屏幕位置 | 键盘按键 |
| --- | --- | --- |
| 高音 | 第 1 行 | `Q W E R T Y U` |
| 中音 | 第 2 行 | `A S D F G H J` |
| 低音 | 第 3 行 | `Z X C V B N M` |

* **风物之诗琴**：21 键，3 行，即上表。
* **沃雅妮莎**：演奏 / 清唱界面同样是 3 行 21 键的演奏系统，默认按上表处理
  （她的区别是"唱"而不是"琴"的音色）。

如果游戏里的键位与默认不同，**直接改 `instruments.json`** 即可（程序首次运行会自动生成）：

```json
{
  "instruments": [
    {
      "id": "vodyanitsa",
      "name": "沃雅妮莎",
      "rows": [
        { "name": "高音", "keys": ["Q","W","E","R","T","Y","U"] },
        { "name": "中音", "keys": ["A","S","D","F","G","H","J"] },
        { "name": "低音", "keys": ["Z","X","C","V","B","N","M"] }
      ]
    }
  ]
}
```

每行 7 个键，按游戏界面**从左到右**的顺序填写；也可以增加行（比如某些乐器键位不同），
程序会自动按 `行数 × 每行键数` 绘制预览。改完保存，重启程序即可。
不确定时用界面上的「测试当前乐器的按键」逐个对照。

## 六、常见问题

**Q1. 点了开始，游戏里没反应？**
1. 先用「测试当前乐器的按键」确认发送通道是否有效；
2. 若原神是**以管理员身份运行**的，本程序也必须用 `以管理员身份启动.bat` 启动
   （Windows 的 UIPI 机制会静默拦掉低权限进程的模拟按键，日志里会写 `SendInput 只成功发送 0/N`）；
3. 在设置里把发送方式依次换成 `scancode`、`keybd_event` 再试（三种方式均已实测可被系统投递）；
4. 确认角色确实处在演奏界面（手持琴、能看到 21 个琴键）。

**Q2. 全屏时看不到程序窗口？**
原神的"全屏"如果是**独占全屏**，任何窗口都无法覆盖它。两个办法：
* 用快捷键（默认 F9 开始/停止、F10 紧急停止），快捷键是全系统生效的；
* 或在游戏里把显示模式改成「无边框窗口 / 窗口化」，程序就能一直浮在最上面。

**Q3. 我切到别的窗口，它还在弹吗？**
不会。只要原神不在前台，程序会在 0.1 秒内停止并松开按键（设置里可关，但不建议关）。

**Q4. `tick` 是多少毫秒？**
本程序里 **1 tick = 1 毫秒**，所以 150 tick = 每秒约 6.7 个音。
如果你的谱子标注的是"50 毫秒 1 tick"之类的标准，把它乘以 50 填进来即可（比如 3 tick → 150）。
单个音符可以用 `A(25)` 这种写法单独指定时间标记，没写的音符才用界面上的「按键间隔」。

**Q4b. `A(25)` 到底是"等 25 再按 A"还是"按完 A 再等 25"？**
默认是前者（先等 25 tick 再按 A，数字属于它自己）。想换成后者：
**设置 → 谱子里的 (N) 时间标记 → 按下这个键后再等 N tick**。切换后立刻生效，不需要重开程序。

**Q5. 日志在哪？**
`logs\genshin_lyre.log`（自动轮转，最多 5 个 × 2MB），崩溃堆栈在 `logs\faulthandler.log`。
界面上「打开日志文件夹」可直接打开。

**Q5b. 标签页 / 区间会记住吗？**
会。所有曲谱标签、每个区间的内容和间隔都在切换标签、退出程序和每 20 秒自动存进
`session.json`，下次打开原样恢复（点「保存谱子…」是另外存成正式的 txt 文件）。

**Q5c. 标签页太多 / 区间太多了？**
曲谱标签最多 12 个、每个谱子最多 20 个节奏区间（按钮点了会有提示）。
不想要的标签点 `×` 关掉，区间用「删除本区间」删掉。

**Q6. 行号显示在哪？能只弹某几行吗？**
行号默认在编辑框**右侧**（设置里可改成左侧），当前行会高亮，下面一行实时显示"第几行、第几列、共几行"。
只想弹其中一段：在「演奏行范围」里填起始行和结束行（例如 11 到 22），留空就是整首。
注意行号是**相对当前区间**算的，多区间时每个区间各自计数。

**Q7. 谱子里有中文/emoji/怪符号会怎样？**
不会崩溃。无法识别的记号会被**当成休止**，并在日志和「检查整首谱子」里逐一提示；
演奏前的预检也会把这些列出来问你确认后才开始。
（这也是为什么程序要"先问一句"：把问题挡在真正按键之前。）

**Q9. 设置里的下拉框点不动 / 一直闪？**
已修复。原因是主窗口每隔 1.5 秒强行把自己提到置顶组最上面，正好盖住下拉列表。现在：
① 只在"置顶状态真的丢了"时才重新置顶，不再反复打乱窗口层次；
② 打开设置/菜单期间临时取消主窗口置顶，并让对话框自己置顶；
③ **默认演奏期间保持置顶**（不勾「演奏时取消置顶」），程序不会被游戏抢走；
   被抢走时按一下开始/停止快捷键也会立刻把自己唤回最前面。
如果还有异常，把设置里的「窗口始终置顶」取消勾选即可彻底排除。

**Q10. 免责声明能关掉吗？**
能。启动弹窗里勾「下次不再弹出」再点同意就不再弹；之后想恢复：设置 → 免责声明与作者 →
勾上「启动时显示免责声明」。想再看一遍就用「重新查看免责声明」。
声明内容固定唯一版本、窗口只读，不允许在弹窗里做任何修改。

**Q6. 想改快捷键但注册失败？**
说明该组合已被别的程序占用（例如某些录屏/加速软件占用 F9），换一个 F1~F12 即可，
也可以直接用界面按钮开始演奏。
