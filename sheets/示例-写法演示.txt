# 原神自动弹琴 谱子
# 乐器: 沃雅妮莎
# 间隔: 180
# 说明: 写法演示（和弦 / 重复 / 休止 / 注释）

# 普通音符：空格分隔
D D A B C

# 括号 = 和弦：括号里的键同时按下（A 和 H 一起按）
(AH) (SF) D

# 括号里也可以写逗号或空格
(A,H) (S F) D

# 重复记号：A*3 = 连按三下 A；Ax2 = 连按两下
A*3 Ax2 D

# 休止：- _ . ~ 都表示停一拍（不按键）
A - B _ C . D ~

# 行内注释：// 或 # 后面的内容会被忽略
E F G   // 这三个音随便写的，替换成你的谱子
H J Q   # 这个也是注释
